# Planner Studio

A free static MVP for creating original printable daily planners.

## Included
- Inspiration image upload
- Rights/originality confirmation
- Basic palette extraction
- Planner section toggles
- Live style controls
- Multiple page sizes
- Layout presets
- Regenerate layout
- PNG export
- PDF export
- Local autosave
- Project JSON backup

## Run
Open `index.html` in a browser, or host the folder with GitHub Pages / Netlify.

## Important
Reference images should only be used for broad inspiration. Do not copy protected artwork, logos, characters, text, or distinctive compositions.
